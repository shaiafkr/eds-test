# breadcrumb

Custom **custom** block. Purpose: breadcrumb navigation trail; alt is a share-links row.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: the trail items in order: a list of links, one link per row or cell, or one line of links separated by > (the last item may be plain text for the current page). For the alt option, the share links (icons such as :facebook: and :x: inside links).
