# listing-filter

Custom **custom** block. Purpose: title and category filter for a cards-listing.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: a row with the listing heading (e.g. Tourist Places), then an optional row "Filter" | comma-separated categories (or a list). Without the options row the dropdown lists the categories found on the cards-listing cards; an "All" entry is always first.

No variations.
