# cards-listing

Custom **cards** block. Purpose: filterable, paginated listing of detail pages (e.g. tourist places).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: image cell | body cell (linked heading, a line starting with "Category" followed by comma-separated categories, teaser text) | optional footer cell with share links. 10 cards show per page; extra cards page automatically.

## Supported variations

No variations.
