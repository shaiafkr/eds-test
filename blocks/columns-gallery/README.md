# columns-gallery

Custom **columns** block. Purpose: photo gallery for a tourist-place page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: images only, in any rows or cells (typically one row: featured image | further images). The first image is featured; the rest form the thumbnail grid. Text in an image's cell becomes its caption.

## Supported variations

No variations.
